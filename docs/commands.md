# Commands

Claude Code slash commands for task automation.

## Available Commands

| Command | Description |
|---------|-------------|
| `/ralph-plan-task` | Interactive planning |
| `/ralph-implement-python-task` | Autonomous implementation |
| `/codex-review` | Code review via Codex |
| `/create-tasks` | Create tasks from notes |
| `/ralph-batch-check` | Run tests after batch |
| `/kube-upgrade-tool` | Kubernetes upgrades |

## Location

```
~/.claude/commands/
├── ralph-plan-task.md
├── ralph-implement-python-task.md
├── codex-review.md
├── create-tasks.md
└── ...
```

## Usage

```
/command-name arguments
```
