# Project and Task Manager

md-task-mcp — markdown-based task management for AI agents.

## Features

- Task CRUD via MCP tools
- CLI tool `tm`
- Web UI at localhost:8080
- File-based storage

## MCP Tools

| Tool | Description |
|------|-------------|
| `tasks()` | List projects/tasks |
| `create_task()` | Create task |
| `update_task()` | Update task |

## Task Fields

- description, status, plan
- body, review, report, blocks
