# Ralph Wiggum Tools

CLI tools for AI agent workflow automation.

## Tools

| Tool | Description |
|------|-------------|
| ralph implement | Autonomous task implementation |
| ralph plan | Interactive task planning |

## Usage

```bash
# Planning (interactive)
ralph plan myproject 1 2 3

# Implementation (autonomous)
ralph implement myproject 1 2 3
```

## Features

- Loop over multiple tasks
- Auto-retry on API timeout
- Batch check after completion
