# ralph-interview-task

Deep interview command to create a detailed task spec.

## Usage

```
/ralph-interview-task project#N
```

## Purpose

- Gather requirements in depth
- Clarify edge cases and constraints
- Produce a detailed spec for planning

## Rules

- **Read-only** — no code changes
- **Interactive** — clarify with user
- **Spec goes to task** — stored for later planning

## Workflow

1. Get task from md-task-mcp
2. Ask probing questions
3. Clarify edge cases
4. Capture acceptance criteria
5. Write spec to task

## Output

Spec includes: Goal, Requirements, Edge cases, Acceptance criteria.
