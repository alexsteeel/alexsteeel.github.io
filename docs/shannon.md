# Shannon

CLI tool for automated penetration testing.

## Features

- Security vulnerability scanning
- Automated exploit testing
- Report generation
- CI/CD integration

## Usage

```bash
shannon scan <target>
shannon report <output>
```

## Capabilities

- Web application testing
- API security scanning
- Authentication bypass detection
- Injection vulnerability detection

## Integration

Runs in docker compose with isolated infrastructure.
