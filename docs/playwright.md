# Playwright

Browser automation for UI testing.

## Features

- Cross-browser testing
- Screenshot capture
- Form interaction
- Network interception

## MCP Integration

Playwright MCP server provides browser control tools:

```
browser_navigate(url)
browser_snapshot()
browser_click(ref)
browser_type(ref, text)
browser_screenshot()
```

## In Workflow

- **Phase 5: UI Review** — visual testing
- **Phase 7: Final Testing** — regression checks
