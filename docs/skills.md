# Skills

Claude Code skills — reusable capabilities.

## Available Skills

| Skill | Description |
|-------|-------------|
| ralph-interview-task | Deep interview for a detailed spec |
| ralph-plan-task | Interactive task planning |
| ralph-implement-python-task | Autonomous implementation |
| ralph-batch-check | Post-batch test verification |
| ralph-review-code / -security / -simplify | Isolated review agents |
| create-tasks | Create tasks from notes |
| codex-review-task | Codex CLI review for a task |
| memorize-task | Update memory with task summary |

## Location

```
~/.claude/skills/
├── ralph-interview-task/
├── ralph-plan-task/
├── ralph-implement-python-task/
└── ...
```

## Usage

Skills are invoked automatically when relevant or via `/skill-name`.
